# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **ComfyUIX Matrix Edition** seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public issue on GitHub.
2. Email security reports directly to the maintainers or use GitHub's private vulnerability reporting feature at:
   `https://github.com/Bonbrake/ComfyUIX/security/advisories/new`

Please include:
- A description of the vulnerability.
- Steps to reproduce or a proof of concept.
- Affected components or modules (e.g., model downloader URL handling, WebSocket framing, file staging).

We will acknowledge receipt within 48 hours and work with you on a swift resolution.
